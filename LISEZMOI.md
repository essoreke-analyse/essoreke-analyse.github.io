# Mon portfolio — mise en ligne sur GitHub Pages

## À compléter avant la mise en ligne
1. **Photo** : ajoute ta photo dans `assets/img/photo.jpg` (format carré, 800×800 px conseillé). Sans photo, tes initiales « EK » s'affichent.
2. **CV** : ajoute ton CV dans `assets/cv.pdf`. Les boutons « Télécharger mon CV » pointent vers ce fichier.

## Mise en ligne (10 minutes, gratuit, sans installer de logiciel)
1. Connecte-toi sur github.com avec le compte `essoreke-analyse`.
2. Clique sur **New repository** et nomme-le exactement : `essoreke-analyse.github.io`. Coche **Public**, puis **Create repository**.
3. Sur la page du dépôt, clique sur **uploading an existing file**.
4. Glisse-dépose **le contenu** du dossier (le fichier `index.html` et le dossier `assets`), pas le dossier lui-même. Clique sur **Commit changes**.
5. Va dans **Settings → Pages**. Dans « Branch », choisis `main` et `/ (root)`, puis **Save**.
6. Après 1 à 2 minutes, ton site est en ligne à l'adresse : **https://essoreke-analyse.github.io**

## Modifier le site plus tard
Sur GitHub, ouvre `index.html`, clique sur le crayon (Edit), modifie le texte, puis **Commit changes**. Le site se met à jour en une minute.

## Alternative : Vercel
Sur vercel.com, crée un compte avec GitHub, clique sur **Add New → Project**, choisis le dépôt, puis **Deploy**. Tu obtiens une adresse du type `essoreke-kiheou.vercel.app`.
